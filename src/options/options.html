Prompt Enhancer

Improves the prompt in the focused text box, in place. It never sends your message for you.

Get started

  1. Add your Groq API key and accept the data notice below.
  2. Click into a prompt box on a website.
  3. Press Alt+Shift+E or click the toolbar icon. Review the result, then send it yourself.

Provider

Active provider

Saved: none. Create a key at console.groq.com → API Keys.

If unchecked, the key is kept in memory only and you re-enter it after each browser restart. Saved keys are stored unencrypted in this Chrome profile: anyone with access to this profile or computer could read them.

Enhancement

Mode

When a result fails a check (for example, it dropped a number from your prompt) it is never inserted automatically. With this on, you may insert it yourself after reviewing. Results that are malformed or answer your prompt instead of rewriting it can only be copied.

Shortcuts
Alt+Shift+E enhance · Alt+Shift+Z restore original

Change them at chrome://extensions/shortcuts

Data & privacy

What gets sent to Groq

When you press Enhance, the text in the focused box — and nothing else from the page — is sent to Groq with your API key, together with this extension's rewriting instructions. No page address, page content, conversation history, or analytics are sent.

Groq's data handling is governed by your Groq account terms. Groq documents that request logs may be kept for up to 30 days, and that Zero Data Retention can be enabled in your Groq console's data controls (verify the current terms at console.groq.com/docs/your-data). Don't enhance text containing passwords, keys, or other secrets.
